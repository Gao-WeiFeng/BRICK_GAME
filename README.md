# 打砖块游戏 (Brick Game)

## 简介

一款基于 Raylib 的 2D 打砖块游戏，支持双人联机、道具系统、多关卡存档，包含完整的碰撞检测、粒子特效、排行榜等功能。

本项目使用面向对象的设计思想，将游戏中的各个对象封装为独立的类，通过 Game 类统一管理整个游戏流程，实现了可扩展、易维护的游戏架构。

## 编译运行

### 环境要求



* CMake >= 3.10

* Raylib >= 4.0

* ENet (网络通信库)

* nlohmann/json (JSON 解析库)

* C++17 兼容的编译器

### 编译步骤



```
mkdir build && cd build

cmake ..

make
```

### 运行游戏



```
./Breakout
```

## 技术细节

### 碰撞检测

使用最近点法实现圆与矩形的碰撞检测，相比分离轴定理，在轴对齐矩形的场景下更加高效，同时保证了碰撞检测的准确性。

### 网络同步

使用 ENet 库实现可靠的 UDP 网络同步，支持状态插值平滑过渡，解决了网络延迟导致的画面卡顿和瞬移问题，实现了流畅的双人联机体验。

### 性能优化



* 粒子系统使用对象池技术，预分配所有粒子，避免频繁的内存分配和释放，大幅提升了粒子特效的性能

* 配置文件驱动，所有游戏参数和关卡都通过 JSON 文件配置，无需修改代码即可调整游戏内容

## AI 使用记录



* 使用 AI 辅助生成了碰撞检测的基础框架，手动调试了边界条件，优化了碰撞后的速度处理

* 使用 AI 解释了多线程同步的原理，优化了网络同步的代码，解决了数据竞争问题
